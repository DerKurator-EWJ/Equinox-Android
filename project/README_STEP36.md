# Equinox v0.6 — Step 36: Unified Capture / Export

Step 36 adds a recording path for the product surface without changing the learning core.

## What is new

- A compact **REC** control in the bottom product bar.
- Android MediaProjection captures the current Equinox product surface as H.264 video.
- The **same PCM blocks generated by the Unified Orchestra** are tapped before AudioTrack, encoded to AAC, and muxed into the same MP4.
- On Android 10+ recordings are written to **Movies/Equinox** through MediaStore.
- The recorder is read-only with respect to MemoryModel: capture/export cannot create observations, relations, macros, predictions, or memories.
- Modern Android media-projection foreground-service requirements are included.

## Important behavior

If the continuous Generative Orchestra is running, its synthesized output is embedded in the MP4. If it is not running, the AAC track remains silent; the recorder does not automatically start the orchestra because output behavior should remain under user control.

The first recording start shows Android's standard screen-capture consent dialog. Stop recording with the REC/stop control. The final file is then committed to the system media library.

## Architecture

`Equinox Core -> Unified Render State -> Unified GPU Canvas`

and in parallel:

`Equinox Core -> Unified Orchestra -> PCM tap -> AAC`

Capture only observes these outputs:

`GPU surface -> MediaProjection -> H.264`

`Orchestra PCM -> AAC`

`H.264 + AAC -> MP4`

No capture state is fed back into the Equinox learner.
