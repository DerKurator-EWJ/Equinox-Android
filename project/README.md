# Equinox v0.6 — Step 46

Current milestone: **External Knowledge Import Interface**.

External teacher/model data can now enter Equinox only through a canonical grounded schema, a dry-run validator and a staged BASE-pack compiler. Optional embeddings can create bounded sparse relation proposals, but cannot invent sensor meaning or bypass the Equinox hierarchy.

Settings -> MEMORY -> KNOWLEDGE BASE contains the external knowledge dry-run/import entry. Valid packs are staged, reread and atomically installed; incompatible active-profile BASE requirements and same-pack downgrades are blocked.

See `README_STEP46.md` and `EXTERNAL_KNOWLEDGE_SCHEMA_EXAMPLE.json`.
