# Equinox v0.6 — Step 31: Unified Orchestra

Step 31 binds the existing generative orchestra to the exact same continuous Reality ↔ Memory state as the single OpenGL canvas.

## What changed

- One continuous `memoryBlend` now drives both GPU image and audio scene.
- Reality side favours immediate live activation and more transient/pulse-like presence.
- Memory side progressively favours expectation, prediction, structural relevance and recalled context.
- No second audio mode or second sound engine is introduced. The same `ContinuousOrchestraEngine` morphs with the canvas.
- Prediction ghost energy fades down toward Reality and becomes stronger toward Memory.
- The orchestra stays read-only: synthesis never writes back into `MemoryModel`.
- Feedback suppression still uses the exact frequencies generated by the current unified orchestra.

The intended product model is now: one core state → one GPU canvas + one orchestra → one continuous Reality/Memory blend.
